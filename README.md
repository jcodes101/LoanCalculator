# 💸 Loan Calculator (JavaFX)

This is a simple **Loan Calculator** desktop application built using **JavaFX**. The app allows users to input a loan amount, annual interest rate, and loan period (in months), and then calculates the monthly payment amount. It also includes a clear button to reset the form.

## 🚀 Features

- User-friendly interface
- Input fields for loan amount, interest rate, and period
- Displays calculated monthly payment
- Clear button to reset all inputs
- Responsive layout with JavaFX GridPane

## 🛠️ Technologies Used

- Java 8+
- JavaFX
